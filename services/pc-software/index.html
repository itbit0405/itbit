장비 제어용 PC 프로그램 개발

장비를 설정하고 제어하거나, 기기에서 나온 데이터를 수집해 분석하는 PC 프로그램을 만듭니다. 현장에서 바로 쓸 수 있는 Windows·Mac 데스크톱 프로그램을 목적에 맞게 개발합니다.

Why ITBIT

잇빗에 맡기면 다른 점

생산 라인의 검사 장비, 연구용 측정기, 기기 설정 도구처럼 PC와 연결해 쓰는 장비가 많습니다. 잇빗은 기기 쪽 펌웨어와 PC 프로그램을 함께 개발해 통신 규격부터 화면까지 한 번에 맞춥니다.

데이터를 모으는 것에서 끝나지 않고, 그래프로 보여 주고 파일로 저장하고 보고서로 정리하는 등 실제 업무 흐름에 맞춘 기능을 만듭니다.

Use Cases

이런 프로젝트에
맡겨 주세요

  • USB·시리얼 등으로 연결된 장비를 PC에서 제어해야 할 때
  • 기기에서 나오는 데이터를 수집해 그래프로 보고 저장해야 할 때
  • 생산·검사 공정에서 쓸 테스트·설정 프로그램이 필요할 때
  • 기존 프로그램이 오래돼 새로 만들어야 할 때

Scope

제공 범위

01

장비 제어 프로그램

연결된 장비를 설정하고 명령을 보내는 프로그램을 개발합니다.

02

데이터 수집·저장

기기 데이터를 실시간으로 받아 저장하고 파일로 내보냅니다.

03

데이터 분석·시각화

수집한 데이터를 그래프와 표로 보여 주고 분석합니다.

04

생산·검사 도구

양산 공정에서 쓰는 테스트, 설정, 펌웨어 기록 도구를 만듭니다.

05

통신 규격 설계

기기 펌웨어와 주고받을 명령과 데이터 형식을 함께 설계합니다.

06

Windows·Mac 지원

사용 환경에 맞춰 Windows와 Mac용으로 개발합니다.

Process

    업무 흐름 분석

  2. 2

    개발·장비 연동

    실제 장비와 연결해 가며 기능과 화면을 개발합니다.

  3. 3

    현장 적용·납품

    현장에서 테스트하고 사용법을 전달한 뒤 이후 개선을 지원합니다.
